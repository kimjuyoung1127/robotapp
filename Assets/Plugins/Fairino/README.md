# FAIRINO C# SDK

이 폴더에는 FAIRINO 로봇 C# SDK DLL을 배치합니다.

## 다운로드

1. GitHub에서 SDK를 다운로드합니다:
   - Repository: `FAIR-INNOVATION/fairino-csharp-sdk`
   - Branch: `main`
2. 공식 ZIP에서 다음 DLL을 이 폴더에 복사합니다:
   - `libfairino.dll`
   - `CookComputing.XmlRpcV2.dll`
3. Unity Editor를 재시작합니다.

## 참고

- SDK가 없어도 `MockFairinoClient`를 통해 오프라인 시뮬레이션이 가능합니다.
- 실기 연동 시에만 DLL이 필요합니다.
