## TopStatusBar 정보 영역 와이어프레임

### 연결 상태 인디케이터
```text
┌───────────────────────────────────────────────────┐
│ 미연결 상태:                                       │
│   ○ 미연결   [모드:--]  [속도:--]  [안전:--]      │
│                                                    │
│ 연결됨/서보OFF:                                    │
│   ● 연결됨   [모드:수동] [속도:30%] [안전:정상]   │
│   ⚠ 서보 OFF                                     │
│                                                    │
│ 정상 운전:                                         │
│   ● 연결됨   [모드:수동] [속도:30%] [안전:정상]   │
│   ✓ 서보 ON                                      │
│                                                    │
│ 에러 상태:                                         │
│   ● 연결됨   [모드:--]   [속도:--]  [⛔ FAULT]    │
│   전체 배경: AccentDanger 10%                     │
└───────────────────────────────────────────────────┘
```

### 제어 버튼 배치
```text
┌────────────────────────────────────────────────┐
│ [서보ON]  [▶시작]  [■정지]  [⏸일시정지]       │
│ [↻동기화] [⟲오류초기화]                       │
│                                                │
│ 버튼 상태 규칙:                                 │
│ - 미연결: 모든 버튼 비활성                      │
│ - 서보OFF: 서보ON만 활성                        │
│ - 서보ON: 시작/동기화 활성                      │
│ - 실행중: 정지/일시정지 활성                    │
│ - Fault: 오류초기화만 활성                      │
└────────────────────────────────────────────────┘
```

## ContextPanel.StatusCard 와이어프레임

```text
┌─ StatusCard ──────────────────┐
│                                │
│  연결    ● 연결됨              │
│  모드    수동                  │
│  서보    ON                    │
│  상태    정지                  │
│  ───────────────────────────  │
│  Fault   없음         [상세▶] │
│  Safety  정상         [상세▶] │
│  ───────────────────────────  │
│  Tool    01                    │
│  User    00                    │
│  Speed   30%                   │
│                                │
└────────────────────────────────┘
```

### 카드 내 상태별 색상

| 필드 | 정상 | 경고 | 위험 |
|------|------|------|------|
| 연결 | `AccentSuccess` 녹색 점 | - | `AccentDanger` 빨간 점 |
| 모드 | `TitleText` 흰색 | `AccentWarning` (Drag) | - |
| Fault | `MutedText` "없음" | - | `AccentDanger` 코드 표시 |
| Safety | `AccentSuccess` "정상" | `AccentWarning` | `AccentDanger` "정지" |

## ViewState 바인딩 (기존 V2 재사용)

| UI 요소 | ViewState 필드 | 타입 |
|---------|---------------|------|
| 연결 인디케이터 | `IsConnected` | bool |
| 모드 라벨 | `ControllerMode` | enum |
| 서보 상태 | `IsEnabled` | bool |
| Mock/Live | `IsMockMode` | bool |
| Drag 상태 | `IsDragMode` | bool |
| 속도 | `SpeedPreset` | float |
| Fault | `FaultSummary` | string |
| Safety | `SafetySummary` | string |
| Tool ID | `ToolId` | int |
| User ID | `UserId` | int |

## 자동 재연결 (A2)

```text
연결 끊김 감지
  → 상태 바: "연결 끊김 — 재연결 시도 중 (3초)"
  → 3초 간격 자동 재시도
  → 카운트다운 표시: "3... 2... 1... 재시도"
  → 최대 10회 시도 후 "자동 재연결 실패. [수동 연결]"
  → 재연결 성공 시 토스트: "연결이 복원되었습니다"
```

## 초보자 친화 요소

1. **상태 전이 시 토스트 알림**: "서보가 켜졌습니다", "동기화 완료"
2. **Fault 발생 시 풀스크린 배너**: 빨간 배경, 큰 글씨, 해결 순서 표시
3. **미연결 시 조작 패널 마스킹**: 반투명 오버레이 + "먼저 연결하세요" 메시지
4. **DryRun 기본 ON**: Live 모드 첫 연결 시 DryRun 자동 활성화
