## 티칭 시퀀스 편집 (WorkTabBar > 티칭)

```text
┌─ 티칭 시퀀스 ────────────────────────────────┐
│                                               │
│  시퀀스 이름: [Pick & Place 기본    ]         │
│                                               │
│  ┌─ 스텝 목록 ───────────────────────────┐   │
│  │                                        │   │
│  │  1. ▶ MoveJ → Home              [⋮]  │   │
│  │     속도: 30%                          │   │
│  │                                        │   │
│  │  2.   MoveJ → Pick-1            [⋮]  │   │
│  │     속도: 20%                          │   │
│  │                                        │   │
│  │  3.   Wait 0.5s                  [⋮]  │   │
│  │                                        │   │
│  │  4.   IO: 그리퍼 닫기            [⋮]  │   │
│  │                                        │   │
│  │  5.   Wait 0.3s                  [⋮]  │   │
│  │                                        │   │
│  │  6.   MoveL → Place-1           [⋮]  │   │
│  │     속도: 15%                          │   │
│  │                                        │   │
│  │  7.   IO: 그리퍼 열기            [⋮]  │   │
│  │                                        │   │
│  │  8.   MoveJ → Home              [⋮]  │   │
│  │                                        │   │
│  └────────────────────────────────────────┘   │
│                                               │
│  [+ 스텝 추가]  [반복: 1회 ▼]                │
│                                               │
│  사용 가능한 블록:                             │
│  [MoveJ] [MoveL] [Wait] [IO] [Call]          │
│                                               │
│  [저장] [시뮬레이션 ▶] [실행 ▶]              │
│                                               │
└───────────────────────────────────────────────┘
```

### 스텝 컨텍스트 메뉴 [⋮]
- 위로 이동 / 아래로 이동
- 복제
- 수정
- 삭제

### 시뮬레이션 vs 실행
- **시뮬레이션**: 3D에서만 시퀀스 재생 (실제 로봇 안 움직임)
- **실행**: Live 모드에서 실제 로봇 구동 (확인 다이얼로그)

## 포인트 데이터 구조

```
Point {
  name: string           // "Pick-1"
  jointValues: double[6] // [12.3, -45.0, 67.8, 0.0, 90.0, -12.5]
  tcpPose: Pose          // {x, y, z, rx, ry, rz}
  coordSystem: enum      // Base | Tool | User
  toolId: int            // 0
  userId: int            // 0
  createdAt: DateTime
  note: string           // 선택적 메모
}
```
